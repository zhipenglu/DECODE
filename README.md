# DECODE
Degenerate Coding for Deamination: saturated RNA constraint quantification
=========================================

DECODE is a two-stage sequence alignment and quantification framework for densely mutated RNA sequencing reads generated by chemical deamination probing (supporting up to 100% sequence divergence). DECODE decouples coordinate discovery from mutation calling:

1. Transition-Invariant Coordinate Alignment (2-Base G/T Space). Reads and dual-strand references (_fwd and _rev contigs) are projected from 4-base (A/C/G/T) into degenerate 2-base purine/pyrimidine (G/T) space ({A, G} -> G; {C, T/U} -> T) while preserving original 4-base sequences in read metadata. Gap-aware alignment with STAR in 2-base space eliminates transition mismatch penalties across standard and long reads.

2. 4-Base Restoration and Bayesian Deamination Calling. Original 4-base read sequences and alignment operations are restored post-mapping. Multi-mapping reads from homologous genes or young paralogs are resolved using structure- and chemistry-informed Bayesian log-likelihood scoring, incorporating directional C -> T vs. bidirectional A <-> G and ensemble reactivity priors. Outputs include per-nucleotide bulk reactivity profiles and single-molecule modification matrices.

3. Dual-Strand Genome and Transcriptome Mappability Benchmarking. Exact (K, E)-mappability analysis using GenMap across read lengths (K = 20 to 1000 nt) and mismatch tolerances (E = 0, 1), stratified across whole-genome, coding exons, nascent introns, lncRNAs, and multicopy/small ncRNAs.

DEPENDENCIES
------------
- Python >= 3.9 (numpy, scipy, pysam, matplotlib)
- STAR >= 2.7
- Samtools >= 1.15
- GenMap >= 1.3.0 (optional, for genome-wide mappability tracks)

REPOSITORY STRUCTURE
--------------------
- decode_index.py          Build dual-strand 2-base (G/T) FASTA and STAR index
- decode_align.py          Project reads to 2-base space, run STAR, restore 4-base BAM
- decode_call.py           Bayesian paralog reassignment and single-molecule/bulk calling
- decode_simulate.py       Synthetic read simulator with tunable deamination rates


WORKFLOW
--------
1. Build Dual-Strand 2-Base Reference and STAR Index. Because reverse-complementing {G, T} yields {C, A}, both forward (_fwd) and reverse-complement (_rev) strands are explicitly indexed in 5' -> 3' G/T space:

     python decode_index.py \
         --fasta reference.fa \
         --gtf annotation.gtf \
         --outdir decode_idx

2. Align Reads in 2-Base Space and Restore 4-Base Alignments. Projects input FASTQ reads to G/T space, aligns against the dual-strand index using STAR, and restores original 4-base sequences into the output BAM:

     python decode_align.py \
         --index decode_idx \
         --r1 reads_R1.fastq.gz \
         --r2 reads_R2.fastq.gz \
         --threads 16 \
         --out aligned_restored.bam

3. Quantify Ensemble Reactivity and Single-Molecule Events. Scores candidate loci for multi-mappers and calls single-molecule and bulk deamination rates against the original 4-base reference:

     python decode_call.py \
         --bam aligned_restored.bam \
         --fasta reference.fa \
         --outdir decode_results

4. Dual-Strand Human Mappability Benchmarking (Optional). Prepares dual-strand hg38 FASTAs and GENCODE biotype BEDs, runs GenMap across K = 20..1000 nt, and generates summary statistics and plots:

     python mappability/01_prepare_refs_and_beds.py \
         --genome hg38.fa \
         --gtf gencode.v33.annotation.gtf \
         --outdir refs_dual_strand
     sbatch mappability/02_build_genmap_indices.slurm
     sbatch mappability/03_run_genmap_array.slurm
     python mappability/04_summarize_and_plot_mappability.py plot
